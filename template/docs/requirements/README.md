# Requirements — {{PROJECT_NAME}}

Single source of truth for *what* the software must do. Assistants update the requirements
**before** coding whenever a session changes scope (see `AGENTS.md` §2).

- One file per requirement, grouped in epic folders: `<epic>/REQ-nnn-<slug>.md`; each epic
  folder has an `EPIC.md` with the epic's goal. IDs are global and never reused.
- Functional requirements are jobs (`type: job`): *When <situation>, I want to <motivation>,
  so I can <expected outcome>.* Non-functional ones are quality goals (`type: quality`).
- Overview: `INDEX.md`, generated by `scripts/req.sh index`. New requirement:
  `scripts/req.sh new <epic> <job|quality> "<title>"`. Validate: `scripts/check-requirements.sh`.
